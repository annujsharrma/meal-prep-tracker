# Meal Prep Tracker

An aesthetic, Apple-inspired web app for tracking recipes and meal prep.

## Features

- Beautiful iOS-style interface with system fonts, soft shadows, and rounded cards
- Recipe library with ingredients, instructions, prep time, and servings
- Weekly meal prep planner
- Mark meals as prepared
- Search and filter recipes
- All data stored locally in your browser (no account needed)
- Fully responsive and optimized for mobile (PWA-ready)

## Design

Follows Apple Human Interface Guidelines:
- Clean visual hierarchy with large titles
- System gray backgrounds (`#F2F2F7`)
- Soft card elevations
- Bottom tab bar navigation
- Accent color `#007AFF`
- Smooth animations and haptic-like feedback

## Usage

1. Open the app (host via GitHub Pages or any static host)
2. Add recipes under the Recipes tab
3. Plan your week in Meal Prep
4. Track what you've prepared

Data persists in localStorage.

## Hosting on GitHub Pages

1. Go to repository Settings → Pages
2. Source: Deploy from branch `main` / root
3. Your app will be live at `https://annujsharrma.github.io/meal-prep-tracker/`

## Tech

Pure HTML, CSS, and JavaScript — no frameworks, instant load, fully offline-capable.
