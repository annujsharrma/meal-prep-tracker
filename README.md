# Meal Prep Tracker

An aesthetic, Apple-inspired web app for tracking recipes and meal prep.

## Features

- Beautiful iOS-style interface with system fonts, soft shadows, and rounded cards
- Recipe library with ingredients, instructions, prep time, and servings
- Weekly meal prep planner
- Mark meals as prepared
- Search and filter recipes
- All data stored locally in your browser (no account needed)
- Fully responsive and optimized for mobile (PWA-ready)

## Design

Follows Apple Human Interface Guidelines:
- Clean visual hierarchy with large titles
- System gray backgrounds (`#F2F2F7`)
- Soft card elevations
- Bottom tab bar navigation
- Accent color `#007AFF`
- Smooth animations and haptic-like feedback

## How to run the app

### Option 1: GitHub Pages (recommended)

**GitHub Pages is not enabled yet.** Enable it in 30 seconds:

1. Go to your repo: https://github.com/annujsharrma/meal-prep-tracker
2. Click **Settings** (top right of the repo page)
3. In the left sidebar, click **Pages**
4. Under **Source**, select **Deploy from a branch**
5. Branch: `main` / Folder: `/ (root)`
6. Click **Save**
7. Wait 1–2 minutes, then visit: **https://annujsharrma.github.io/meal-prep-tracker/**

### Option 2: Open locally

1. Clone the repo or download the ZIP
2. Open `index.html` in your browser

Data is saved in your browser’s localStorage and persists across sessions.

## Usage

1. Add recipes with the + button
2. Go to the Meal Prep tab and tap a meal slot to assign a recipe
3. Tap the circle to mark a meal as prepared
4. Check Progress for your weekly stats

## Tech

Pure HTML, CSS, and JavaScript — no frameworks, instant load, fully offline-capable.
